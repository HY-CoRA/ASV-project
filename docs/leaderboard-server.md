# 명예의 전당 서버

Node.js 24 이상의 내장 HTTP 서버와 `node:sqlite`를 사용합니다. 별도 패키지 설치 없이 게임 화면과 명예의 전당 API를 같은 포트에서 제공합니다.

```sh
node server.cjs --host 0.0.0.0 --port 5211 --static-dir . --db ../work/asv-leaderboard.sqlite
node --test test/server.test.cjs
```

기본 포트는 `5211`, 바인딩 주소는 `0.0.0.0`입니다. `--static-dir`을 생략하면 저장소 폴더를 사용하며, 기본 DB는 저장소 밖의 `../work/asv-leaderboard.sqlite`에 만듭니다. 운영 시 DB와 SQLite의 `-wal`, `-shm` 파일을 정적 웹 폴더 밖에 유지하고 함께 보관하세요. 서버를 재시작해도 도전 기록과 순위가 유지됩니다.

API는 같은 출처의 상대 경로로 호출합니다. 별도의 CORS 설정은 필요하지 않습니다. 임시 주소 게이트웨이는 `/api/` 요청을 이 서버로 전달해야 합니다.

| 요청 | 내용 |
| --- | --- |
| `GET /api/health` | 서버 상태 |
| `POST /api/attempts` | `{level: 1 또는 2}`로 서버가 생성한 지도와 도전 ID를 발급 |
| `POST /api/attempts` | `{level, retryOf: 이전도전ID}`로 완료한 지도의 재도전 생성 |
| `POST /api/attempts/:id/finish` | `{program: AST배열}`로 서버에서 저장된 지도를 재실행하고 결과를 확정 |
| `POST /api/attempts/:id/entry` | `{name: 이름}`으로 확정된 결과를 명예의 전당에 등록 |
| `GET /api/leaderboard?level=1` | 난이도별 상위 10개 기록과 전체 등록 수 |

시간 값은 밀리초입니다. `startedAt`, `serverNow`, `createdAt`은 Unix epoch 기준이며, `elapsedMs`는 서버가 측정한 풀이 시간입니다. 재도전 응답의 `elapsedBaseMs`에는 이전 풀이 시간이 포함됩니다. 결과 화면이나 이름 입력창에서 보낸 시간은 재도전의 풀이 시간에 더하지 않습니다. 새 지도로 바꾸면 풀이 시간을 새로 측정합니다.

클라이언트가 보내는 점수와 시간은 사용하지 않습니다. 서버는 발급한 지도에서 블록을 다시 실행해 점수, 동작 수와 종료 여부를 결정합니다. 프로그램에는 `move`, `left`, `right`, `pick`, `checkout`, `repeat`, `if`만 허용합니다. 블록은 500개, 중첩은 12단계, 반복 횟수는 1~20회로 제한하며 엔진은 최대 600단계에서 중단합니다. `checkout`은 한 번만 배치할 수 있습니다. `blocks`에는 암묵적인 시작하기 블록 1개가 포함됩니다.

첫 완료 결과는 고정되며 동일한 완료 요청은 저장된 결과를 반환합니다. 종료하기를 실행했거나 이스터에그 실패 엔딩에 도달한 도전은 등록할 수 있습니다. 종료되지 않은 결과는 저장할 수 있지만 명예의 전당에는 등록되지 않습니다. 같은 도전의 이름 등록은 중복 요청에도 한 번만 이루어집니다. 이름은 제어 문자 없이 1~12자입니다.

순위는 **점수 높은 순 → 풀이 시간 짧은 순 → 등록 시각 빠른 순 → 등록 ID 작은 순**입니다. 난이도별로 분리합니다. 등록 응답에는 본인 기록, 전체에서의 `rank`, 상위 10개 `entries`가 들어갑니다. 실패 엔딩의 `verdict`는 `easterEgg`, `ending`은 물건 이름(`양말`, `축구공`, `로봇`)입니다.

도전 ID의 유효 기간은 발급 후 24시간입니다. 만료된 도전은 `410`, 잘못된 입력은 `400`, 미완료 기록 등록은 `409`, 없는 도전은 `404`를 반환합니다. 등록된 순위 기록은 도전이 만료되어도 유지됩니다. 정적 서버는 게임용 HTML/CSS/JS 및 리소스만 제공하며 서버 코드, 테스트, Git 파일, DB 파일과 정적 폴더 밖을 가리키는 심볼릭 링크는 제공하지 않습니다.
