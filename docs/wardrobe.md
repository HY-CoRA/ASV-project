# 나우 꾸미기

인트로의 **나우 꾸미기**에서 여자 나우·남자 나우를 고르고, 각 캐릭터의 머리·의상·소품·장바구니를 조합할 수 있습니다. 기본 모습으로 바로 게임을 시작할 수도 있습니다.

- 머리 4종 / 머리색 4종 / 피부색 4종
- 의상 4종: 구름 후드, 딸기 멜빵, 꼬마 파티시에, 별빛 야구 점퍼
- 소품 4종: 없음, 체리 리본, 레몬 모자, 소다 헤드폰
- 장바구니 4종: 민트 마켓, 딸기 우유, 소풍 바구니, 별빛 한 스푼

모든 조합은 두 캐릭터 모두 사용할 수 있습니다. 캐릭터를 바꿔도 각자 선택 중인 조합은 유지됩니다. **이 모습으로 준비 완료**를 누르면 적용·저장되며, **돌아가기**는 저장하지 않고 돌아갑니다. **기본 모습으로**는 현재 캐릭터만 초기화합니다. 결과 화면에서도 꾸미기를 열 수 있으며 기존 블록은 유지됩니다.

선택한 나우는 인트로 미리보기, 지도, 말풍선, 결과에 표시됩니다. 장바구니는 캐릭터 손과 실시간 장바구니 제목에 표시되고 패널 테두리에도 색이 반영됩니다. 수집한 재료는 기존처럼 케이크 층으로 순서대로 표시됩니다.

꾸미기는 점수·맵·능력·레시피·실행 규칙에 영향을 주지 않습니다. 네 방향 모습과 방향 화살표를 함께 표시합니다. 기존 레벨 고정 URL도 유지합니다.

## 저장

브라우저의 `nau_cake_wardrobe_v1` localStorage 키에 캐릭터별 선택을 저장합니다. 서버 또는 다른 기기와 동기화하지 않습니다. 저장이 차단돼도 현재 페이지에서는 적용할 수 있고, 저장 실패 안내가 표시됩니다. 명예의 전당 데이터는 변경하지 않습니다.

## 파일 및 에셋

- `js/wardrobe.js`: 선택 상태, 저장, 꾸미기 UI, 도트 캐릭터·장바구니 SVG 생성
- `css/wardrobe.css`: 남색·민트·크림·분홍의 옷장 화면과 작은 화면 레이아웃
- `index.html`, `js/app.js`: 화면 진입 및 기존 게임과의 연결

도트 캐릭터와 장바구니는 이 프로젝트를 위해 코드로 직접 그린 원본 SVG입니다. 참고 이미지의 캐릭터, 브랜드 로고, 그림 파일은 사용하지 않았습니다. 외부 에셋·라이브러리·CDN 의존성을 추가하지 않았습니다.

## 확인

```sh
node test/engine.test.js
node test/wardrobe.test.js
```

화면 확인: 인트로에서 꾸미기 진입 → 두 캐릭터의 조합 변경 → 저장 → 시작 → 이동/회전/집기 → 결과에서 꾸미기 → 다시 도전. 취소 시 기존 모습 유지, 새로고침 시 복구, `?level=1&lock=1`, 레벨 2·3, 360px 폭, 키보드 탭·방향키 조작도 확인합니다.
