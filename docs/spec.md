# ASV-project — 프로젝트 개요 및 개발 기준

## 기준 문서

전체 기능 요구사항, 규칙, 화면 기준, 완료 체크리스트와 확인 시나리오는 [장보기 게임 개편 작업 명세](shopping-game-rework.md)에 모아 둔다. 구현과 검토는 해당 문서를 기준으로 진행한다. 이 문서는 프로젝트 목적과 핵심 방향을 요약하며, 별도 기능 규칙을 추가하거나 작업 명세를 대체하지 않는다.

## 프로젝트 목적

안산 사이언스 밸리(ASV) 부스에서 초등학생이 블록 코딩의 순차·반복·조건 개념을 연습하는 브라우저 게임이다. 아이들은 마트 지도에서 나우를 이동시키고 장보기 품목을 장바구니에 담은 뒤, 코드 마지막의 `계산하기` 블록으로 결과를 확인한다.

## 레벨 요약

| 레벨 | 대상 | 지도 크기 | 필수 장보기 품목 | 함정 |
|---|---|---:|---|---|
| 1 | 초등 1~3학년 | 5×5 | 토마토, 감자, 고구마 | TNT |
| 2 | 초등 4~6학년 | 7×7 | 계란, 베이컨, 빵, 케첩, 우유 | 초콜릿, 양말, 다이아몬드 |

아이템이 놓인 칸은 이동할 수 있다. 나우가 그 칸에 도착한 다음 `여기 물건 담기` 블록을 실행하면 현재 칸의 물건을 장바구니에 담는다. 각 레벨은 가까운 품목까지 이동해 담는 약 3개의 연결된 가이드 블록으로 시작한다.

## 화면과 완료 흐름

- 기존 시각 스타일을 유지하며 게임 콘텐츠를 케이크 만들기에서 장보기로 전환한다.
- 장보기 목록, 지도, 장바구니, Blockly와 실행 컨트롤은 플레이 화면 한 화면에 보이도록 배치한다. 페이지 세로 스크롤은 만들지 않는다.
- 최상단 흰색 바와 긴 규칙/블록 설명 패널은 제거하고, Blockly 위에 간단한 점수 안내를 둔다.
- 계산대에 도착하는 방식은 사용하지 않는다. `계산하기`가 마지막 실행 블록으로 실행되어야 결과 화면으로 넘어간다.

## 프로젝트 구성

| 경로 | 역할 |
|---|---|
| `index.html` | 화면 마크업 |
| `css/style.css` | 시각 스타일과 반응형 레이아웃 |
| `js/engine.js` | 레벨 데이터, 이동 및 명령 실행, 점수 계산 |
| `js/app.js` | Blockly, 화면 전환, 장바구니 및 결과 UI |
| `vendor/` | Blockly 라이브러리와 한국어 메시지 |
| `test/engine.test.js` | 엔진 동작 테스트. 개편 구현 시 새 명세와 일치하도록 갱신 |

## 실행

정적 프로젝트로 빌드 단계 없이 실행한다. 저장소 루트에서 아래 명령을 사용한다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`으로 접속한다.
