- 정리일: 2026-11-05
- 대상: `HY-CoRA/ASV-project`, `tomatolovers`
- 요구사항 기준: [장보기 게임 개편 작업 명세](shopping-game-rework.md)
- 상태: 기능 개편과 주요 실행 흐름 검증 완료. 사용자 요청으로 추가 테스트를 중단하고 현재 구현·테스트·문서를 함께 저장한다.

## 앞서 완료한 자동 검증

`node test/engine.test.js`가 담기·점수 테스트를 함께 실행하며 통과했다. JavaScript 구문 검사도 통과했다. 이번 저장 단계에서는 테스트를 다시 실행하지 않았다.

- 두 레벨의 지도 크기와 정방향·역방향 장보기 경로, 원본 지도 보존
- 현재 칸 담기, 빈 칸 담기, 재획득 방지, 초기화 시 품목 복원
- 올바른 계산하기와 중간·중첩·중복 계산하기의 종료 판정
- 순서와 무관한 품목별 +50점, 중복 0점, 일반 함정 −20점, TNT −100점, 최저 0점
- 누락 품목, TNT 즉시 종료, 벽·조건·반복, 실행 상한, 순위 동점 비교

## 앞서 완료한 브라우저 검증

로컬 서버와 내장 브라우저에서 실제 게임 화면의 실행·멈춤·재도전 버튼으로 확인했다. 긴 경로는 `test/browser-scenarios.html`에서 Blockly 입력 블록만 불러왔고, 이동·점수·결과 처리는 실제 게임 코드를 사용했다. 가이드에 계산하기를 직접 끌어 연결하는 조작도 확인했다.

| 실행 흐름 | 관찰 결과 |
|---|---|
| 레벨 1 필수 품목 완주 → 계산 | 150점, 필수 3종, 누락 없음 |
| 레벨 2 필수 품목 완주 → 계산 | 250점, 필수 5종, 누락 없음 |
| 레벨 2 필수 품목 + 함정 3종 → 계산 | 190점, 담은 8종과 감점 표시 |
| 레벨 1 토마토 → TNT | 즉시 종료, 0점, 누락 품목 표시 |
| 일부 품목 또는 빈 장바구니 → 계산 | 각각 50점/0점과 누락 정보 표시 |
| 가이드만 실행, 계산하기 없음 | 첫 품목을 담고 플레이 화면 유지, 계산하기 안내 |
| 계산하기 뒤 이동 / 반복 안 계산하기 / 떨어진 블록 | 실행 전에 안내, 지도·점수 변화 없음 |
| 실행 중 멈춤 | 멈춘 뒤 추가 이동 없이 편집·재실행 가능 |
| 결과에서 다시 도전 | 블록 유지, 시작 위치·지도·장바구니·점수 초기화 |
| 블록 지우기 → 가이드 다시 놓기 | 빈 작업 공간에서 연결된 가이드 3개 복원 |
| 명예의 전당 등록 | 등록 완료 표시, 같은 브라우저에서 레벨별 기록 유지 |

## 화면 검증에서 반영한 개선

- 지도 영역을 정사각형으로 유지하고 장바구니 공간을 미리 확보해 품목이 늘 때 지도 위치가 흔들리는 현상을 줄였다.
- 작은 화면의 장바구니를 2열로 정리하고, 375×667에서 8개 품목이 점수 영역과 겹치지 않는 것을 확인했다.
- 실행 중 편집과 중복 실행을 잠그고, 현재 실행 블록이 편집기 밖으로 나가면 해당 블록으로 이동한다.
- 결과 화면에서 점수와 재도전을 순위 목록보다 먼저 볼 수 있도록 배치를 조정했다.
- 선택 카드·버튼·품목의 어두운 테마 대비, 상태 안내, 현재 위치 표시를 보완했다.

1280×720, 1024×600, 768×1024, 515×704, 390×844, 375×667 크기에서 플레이 화면 배치와 페이지 스크롤을 살펴봤다. 마지막 재점검에서는 1366×768과 1280×720의 배치 조건이 통과했으나, 1024×600에서 장바구니와 점수의 6px 겹침이 발견됐다.

이를 보정하기 위해 데스크톱 장바구니를 4열, 너비 1050px 이하에서는 3열로 고정하고 장바구니 영역 높이를 늘렸다. **이 마지막 CSS 보정 이후의 화면 재검증은 하지 않았다.** 따라서 모든 화면 크기의 최종 검증 완료로 표시하지 않는다.

## 검증 범위와 남은 확인 사항

- 사용자 요청에 따라 추가 테스트를 중단했다. 추후 화면 검증을 재개한다면 마지막 장바구니 간격 보정의 영향을 먼저 확인한다.
- 크기별 확인은 브라우저 뷰포트/iframe 기준이며, 실제 휴대폰 터치 조작과 Safari는 검증하지 않았다.
- GitHub Pages 배포 결과는 이번 로컬 검증 범위에 포함하지 않았다.
- 순위는 브라우저의 로컬 저장소에 저장되며 저장소에 커밋되지 않는다. 검증용 `UI검증_L1/L2` 기록은 테스트 페이지의 `검증용 순위 기록 정리` 버튼으로 정리할 수 있다. 검증 탭이 닫힌 뒤 정리 여부는 재확인하지 않았다.

## 재현 도구

```bash
node test/engine.test.js
python3 -m http.server 8000
```

- 일반 플레이: `http://localhost:8000/index.html`
- 검증용 블록 입력·화면 크기 조절: `http://localhost:8000/test/browser-scenarios.html`
- 시나리오 데이터: `test/scenario-data.js`의 완주·함정·계산 오류·멈춤·조건·품목 배치 사례 14개

테스트 페이지는 검증 보조 도구이며 일반 플레이 화면에서 연결하지 않는다.
