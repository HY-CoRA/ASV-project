우당탕탕! 나우의 장보기 대작전

오늘은 사랑하는 엄마의 생신! 길치인 나우를 도와 마트에서 케이크 재료를 사 와야 해요. 하지만 코딩을 한 칸이라도 틀리면… 케이크에 양말이나 벽돌이 들어갈지도 몰라요.

  1. 블록을 끌어다 나우가 움직일 순서를 짜요.
  2. 실행하면 나우가 마트를 돌며 앞에 있는 물건을 집어요.
  3. 집은 순서 그대로 케이크가 쌓여요. 빵 → 생크림 → 빵 → 생크림 → 토핑 → 초 가 정답!

블록 설명과 규칙
  • 앞으로 가기 — 보는 방향으로 한 칸. 선반(벽)이면 "쿵!" 하고 그 자리에 있어요.
  • 왼쪽/오른쪽으로 돌기 — 제자리에서 90도 회전.
  • 앞에 있는 물건 집기 — 바로 앞 칸에 물건이 있으면 장바구니에 넣어요. 없으면 허공을 집어요.
  • N번 반복하기 — 안에 넣은 블록을 N번 실행.
  • 만약 ~라면 — 앞에 벽이 있다면 / 없다면, 마지막으로 집은 게 빵이라면 / 생크림이라면.
  • 다이너마이트를 집으면 바로 폭발, 계산대에 들어가면 장보기 끝.
  • 점수: 정상 재료 +50, 순서 오류 −10, 이상한 재료 −20, 다이너마이트 −100. 같은 점수면 블록이 적은 쪽이 위.
