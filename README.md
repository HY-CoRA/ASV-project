# ASV-project — 블록 코딩 장보기 게임

안산 사이언스 밸리(ASV) 부스용 블록 코딩 교육 게임. 아이들이 레벨에 맞는 장보기 목록을 확인하고, 블록으로 나우를 움직여 필요한 물건을 장바구니에 담는다. 장보기를 마치려면 프로그램 마지막에 `계산하기` 블록을 실행한다.

[플레이 방법 안내](#플레이-방법)

## 작업 기준

- 전체 요구사항, 완료 기준, 구현 확인 시나리오: [장보기 게임 개편 작업 명세](docs/shopping-game-rework.md)
- 프로젝트 개요와 해당 명세의 요약: [개발 명세](docs/spec.md)
- 두 문서의 세부 기준이 다르게 보이면 `docs/shopping-game-rework.md`를 단일 기준으로 삼는다.

## 개편 목표

| 레벨 | 대상 | 지도 | 장보기 목록 | 함정 |
|---|---|---:|---|---|
| 1 | 초등 1~3학년 | 5×5 | 토마토, 감자, 고구마 | TNT |
| 2 | 초등 4~6학년 | 7×7 | 계란, 베이컨, 빵, 케첩, 우유 | 초콜릿, 양말, 다이아몬드 |

- 아이템이 놓인 칸으로 이동해 `여기 물건 담기` 블록으로 현재 칸의 아이템을 담는다.
- Blockly는 각 레벨에서 가장 가까운 품목까지 이동해 담는 약 3개의 연결된 가이드 블록과 함께 시작한다.
- 블록 코딩 영역 위에 짧은 점수 안내를 표시하고, 계산대와 긴 규칙 패널은 제거한다.
- 기존 색상, 글꼴, 버튼 및 블록의 시각 스타일은 유지한다. 플레이 화면의 핵심 UI가 세로 스크롤 없이 보이도록 한다.

## 구현 상태

`tomatolovers` 작업본에 장보기 개편을 구현했다. 두 레벨의 전체 실행·계산·결과·재도전 및 엔진 회귀 테스트를 통과했다. 화면 검증에서 발견한 장바구니 간격을 보정했으며, 마지막 CSS 보정 후 추가 화면 테스트는 사용자 요청에 따라 생략했다. 완료 범위와 남은 확인 사항은 [UI 검증 기록](docs/qa-report.md)을 참고한다.

## 플레이 방법

빌드나 패키지 설치 없이 실행할 수 있다. 먼저 `tomatolovers` 브랜치의 프로젝트 전체를 클론하거나 GitHub의 **Code → Download ZIP**으로 내려받아 압축을 푼다.

### 파일로 바로 실행

1. 내려받은 프로젝트 폴더의 `index.html`을 Chrome이나 Edge로 연다.
2. 레벨을 선택하고 **게임 시작하기**를 누른다.
3. 가이드 블록에 이동·회전 블록을 이어 붙이고, 물건이 있는 칸에서 **여기 물건 담기**를 사용한다.
4. **계산하기**를 반복·조건 블록 밖의 맨 마지막에 한 개 연결한다.
5. **실행**을 눌러 장보기 결과를 확인한다. **다시 도전**을 누르면 블록을 유지한 채 다시 시작한다.

### 로컬 서버로 실행

Python이 설치되어 있다면 프로젝트 폴더에서 터미널을 열고 다음 명령을 실행한다.

```bash
python -m http.server 8000 --bind 127.0.0.1
```

환경에 따라 `python` 대신 `python3` 또는 `py`를 사용한다. 서버가 실행 중일 때 브라우저 주소창에 `http://localhost:8000`을 입력한다. 종료하려면 터미널에서 `Ctrl+C`를 누른다. 이 주소는 서버를 실행한 컴퓨터에서 사용하는 로컬 주소다.

## 구조

```
index.html          화면 마크업
css/style.css       화면 스타일과 반응형 레이아웃
js/engine.js        레벨 데이터, 이동과 블록 실행, 점수 계산
js/app.js           Blockly, 게임 화면, 결과 화면과 UI 동작
vendor/             Blockly 및 한국어 메시지
test/engine.test.js 장보기 엔진 회귀 테스트
docs/spec.md        프로젝트 개요 및 기준 문서 링크
docs/shopping-game-rework.md  구현 요구사항, 완료 기준과 확인 시나리오
```

## 게시

장보기 개편본은 별도 배포가 필요하다. 개편본 게시 시 배포 대상과 실제 실행 버전을 확인한다.

## 검증

```bash
node test/engine.test.js
```

로컬 서버에서 `test/browser-scenarios.html`을 열면 완주·함정·계산 오류 등의 예제 블록을 불러올 수 있다. 예제는 테스트 페이지에서만 입력하며, 실행·점수·결과 표시는 실제 게임 코드를 사용한다. 일반 플레이 진입점은 `index.html`이다.
