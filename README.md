# ASV-project — 심부름 장보기

안산 사이언스 밸리(ASV) 부스용 블록 코딩 게임. 부탁받은 장보기 목록을 담도록 나우의 움직임을 블록으로 짠다.

## 실행

Node.js 24 이상으로 게임과 명예의 전당 서버를 실행한다. 별도 패키지 설치나 빌드는 필요 없다.

```bash
node server.cjs --host 0.0.0.0 --port 5211
```

다른 PC의 브라우저에서 [테스트 게임](http://100.64.0.19:5211/)을 연다. 해당 주소로 연결되는 네트워크가 필요하다. 가로 태블릿에서는 지도와 블록 편집기를 한 화면에 표시한다.

## 난이도와 규칙

| 난이도 | 내용 | 주소 |
|---|---|---|
| 초1–3 | 6×6 무작위 미로, 딸기·브로콜리·사과 3개, 함정 1개 | `?level=1` |
| 초4–6 | 8×8 무작위 미로, 딸기·브로콜리·사과·당근·바나나 5개, 함정 3개 | `?level=2` |

`?level=2&lock=1`처럼 지정하면 부스 기기에서 난이도를 고정할 수 있다.

- 물건 칸으로 이동한 뒤 **서 있는 물건 집기**를 실행한다. 한 칸의 물건은 한 번만 담을 수 있다.
- 두 난이도에서 이동·회전·집기·반복·조건 블록을 모두 사용할 수 있다.
- 목록에 있는 물건은 어느 순서로 담아도 된다. 각각 +50점이며 만점은 초1–3 150점, 초4–6 250점이다. 양말·축구공·로봇처럼 목록에 없는 물건이나 중복으로 담은 물건은 −20점이다.
- 양말·축구공·로봇을 집으면 각각 세탁소·마트 월드컵·댄스 파티 이스터에그가 발동한다. −20점을 반영하고 남은 블록을 중단해 물건별 실패 결과를 표시한다. 종료 블록이 없어도 이 결과를 표시하며, 이름을 입력하면 도전 기록을 명예의 전당에 남길 수 있다.
- 물웅덩이·미끄러운 바닥은 밟으면 −10점이다. 같은 함정은 한 실행에서 한 번만 감점하며, 모든 지도에 함정을 피해서 목록 전체를 담을 수 있는 길이 있다.
- **시작하기**에 연결된 블록만 실행한다. 시작하기와 **종료하기**는 각각 하나만 놓을 수 있으며, 분리된 블록은 실행과 결과 블록 수에 포함하지 않는다. 종료하기를 만나면 점수를 계산한다. 종료 블록이 없으면 연결된 코드 끝에서 멈추고, 중첩 반복도 600회 실행 한도를 넘기면 중단한다.
- 게임을 시작하거나 **새 맵**을 누르면 난이도에 맞는 지도를 생성한다. 실행·초기화·다시 도전은 같은 지도를 유지한다.

## 풀이 시간과 명예의 전당

- 지도를 열면 상단 타이머가 시작되고, 실행이 끝나면 이름 입력 모달이 먼저 열린다. 이름 입력과 결과 화면을 보는 시간은 풀이 시간에서 제외한다.
- 같은 맵에서 다시 도전하면 지도와 코드를 유지하고 이전 풀이 시간을 누적한다. 새 맵에서는 새 타이머를 시작한다.
- 기록은 난이도별로 점수 내림차순, 풀이 시간 오름차순으로 정렬한다. 완전히 같은 기록은 먼저 등록한 순서로 표시한다.
- 점수와 풀이 시간은 서버에서 확정한다. 서버는 시작할 때 지도를 저장하고 제출된 블록 프로그램을 같은 엔진으로 다시 실행한다.
- 종료하기 또는 이스터에그 엔딩으로 끝난 기록만 등록할 수 있다. 종료 블록 없이 코드가 끝난 경우에도 이름 모달과 결과는 표시하지만 순위에는 등록하지 않는다.
- SQLite 데이터는 기본적으로 저장소 바깥 `../work/asv-leaderboard.sqlite`에 저장한다. `--db /절대/경로/leaderboard.sqlite`로 변경할 수 있으며 웹 정적 파일 경로 바깥에 둔다. 서버를 재시작해도 기록은 유지된다.
- 결과의 지도에는 실제로 지나간 칸, 수집한 물건, 멈춘 위치를 표시한다.

## 테스트

```bash
node test/engine.test.js
node test/blocks.test.js
node --test test/server.test.cjs
```

엔진 규칙과 함정 감점을 검증하고, 각 난이도 160개 시드에서 모든 물건의 도달 가능성, 함정 없는 정답 경로, 이동·회전 난이도와 지도의 다양성을 확인한다. `NauEngine.generateLevel(idOrLevel, random?)`에 난수 함수를 전달하면 같은 시드로 지도를 재현할 수 있다.

이전 케이크 데모의 기획 기록은 [docs/spec.md](docs/spec.md)에 남아 있다.
