# ASV-project — 심부름 장보기

안산 사이언스 밸리(ASV) 부스용 블록 코딩 게임. 부모님이 부탁한 딸기와 브로콜리를 담도록 나우의 움직임을 블록으로 짠다.

## 실행

빌드 없이 `index.html`을 브라우저에서 열거나 로컬 서버를 띄운다.

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 [로컬 게임](http://127.0.0.1:8000/)을 연다. 가로 태블릿에서는 지도와 블록 편집기를 한 화면에 표시한다.

## 난이도와 규칙

| 난이도 | 내용 | 주소 |
|---|---|---|
| 초1–3 | 짧은 길에서 기본 블록으로 딸기와 브로콜리 담기 | `?level=1` |
| 초4–6 | 반복·조건 블록으로 미로를 돌며 바나나 등 목록에 없는 물건 가려내기 | `?level=2` |

`?level=2&lock=1`처럼 지정하면 부스 기기에서 난이도를 고정할 수 있다.

- 물건 칸으로 이동한 뒤 **서 있는 물건 집기**를 실행한다. 한 칸의 물건은 한 번만 담을 수 있다.
- 딸기와 브로콜리는 어느 순서로 담아도 된다. 목록에 있는 물건은 각각 +50점, 목록에 없거나 중복으로 담은 물건은 −20점이다.
- 프로그램 마지막에 **종료 / 계산하기** 블록을 연결한다. 이 블록이 실행되면 점수를 확인하고 기기별 명예의 전당에 등록할 수 있다.
