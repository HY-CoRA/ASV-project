# ASV-project — 심부름 장보기

안산 사이언스 밸리(ASV) 부스용 블록 코딩 게임. 부탁받은 장보기 목록을 담도록 나우의 움직임을 블록으로 짠다.

## 실행

Node.js 24 이상으로 게임과 명예의 전당 서버를 실행한다. 별도 패키지 설치나 빌드는 필요 없다.

```bash
node server.cjs --host 0.0.0.0 --port 5211
```

다른 PC의 브라우저에서 [테스트 게임](http://100.64.0.19:5211/)을 연다. 해당 주소로 연결되는 네트워크가 필요하다. 가로 태블릿에서는 지도와 블록 편집기를 한 화면에 표시한다. 게임은 화면 전체 너비를 쓰고, 심부름 목록을 제외한 높이에 맞춰 지도 영역과 칸 안의 그림·글자를 조절한다. 주요 버튼은 48px 이상의 터치 영역을 두고, 블록은 두 손가락이나 ＋/− 버튼으로 확대·축소할 수 있다. 종료하기는 기본 이동·집기 블록 바로 아래에 둔다.

## 태블릿에 앱 설치

- 배포된 **HTTPS 주소**를 태블릿 브라우저에서 열고 상단 **앱 설치**를 누른다. `http://100.64.0.19:5211/` 같은 원격 HTTP 주소는 앱 설치용으로 사용할 수 없다.
- 안드로이드 Chrome/Edge는 설치 창을 사용한다. 설치 창이 지원되지 않으면 브라우저 메뉴의 **앱 설치** 또는 **홈 화면에 추가**를 안내한다.
- 아이패드는 Safari의 **공유 → 홈 화면에 추가**를 이용한다. **웹 앱으로 열기**가 있으면 켠다. 설치 후에는 앱 아이콘으로 주소창 없는 화면을 연다.
- 설치한 앱에서는 설치 버튼을 숨긴다. 가로·세로 회전을 모두 지원한다.
- 시작 화면과 게임 화면 파일은 기기에 저장한다. 새 지도 생성과 결과·명예의 전당 저장에는 인터넷 연결이 필요하며, 연결이 끊기면 안내를 표시한다. API 응답과 사용자 기록은 오프라인 캐시에 저장하지 않는다.
- 앱 업데이트는 진행 중인 게임을 강제로 새로고침하지 않는다. 앱을 완전히 닫았다가 다시 열면 다음 버전을 적용한다. 다른 공개 주소의 캐시에는 영향을 주지 않는다.

## 난이도와 규칙

| 난이도 | 내용 | 주소 |
|---|---|---|
| 초1–3 | 5×5 무작위 미로, 16종 중 랜덤 재료 3개, 바닥 함정 1개·엉뚱한 물건 1개 | `?level=1` |
| 초4–6 | 8×8 무작위 미로, 16종 중 랜덤 재료 5개, 바닥 함정 3개·엉뚱한 물건 3개 | `?level=2` |

`?level=2&lock=1`처럼 지정하면 부스 기기에서 난이도를 고정할 수 있다.

- 물건 칸으로 이동한 뒤 **서 있는 물건 집기**를 실행한다. 한 칸의 물건은 한 번만 담을 수 있다.
- 두 난이도에서 이동·회전·집기·반복·조건 블록을 모두 사용할 수 있다.
- 새 지도를 만들 때 16종의 재료에서 중복 없이 장보기 목록을 고른다. 딸기·브로콜리·바나나·사과·당근에 오렌지·포도·수박·복숭아·배·파인애플·레몬·체리·오이·옥수수·감자를 더했다. 같은 맵의 실행·미리보기·다시 도전에서는 목록을 유지한다.
- 도전 방식은 **랜덤 도전** 하나이며, 시작할 때마다 지도와 목록을 새로 고른다. 같은 지도와 목록을 받은 기록끼리만 순위를 비교한다.
- 처음 화면의 **시작하기**를 누르면 게임 위에 그림 안내가 먼저 열린다. 블록 8종 → 벽·함정·깜짝 물건 → 이번 심부름 목록과 목표를 세 단계로 살펴보고 **확인했어요! 시작**을 누르면 조작과 시간 측정이 시작된다. 안내 중에는 편집·실행을 잠그며, 홈으로 또는 뒤로 가기로 취소할 수 있다. 게임 안의 새 맵·재도전은 바로 이어서 시작한다.
- 심부름 목록의 재료를 누르면 지도에서 그 재료가 있는 칸만 2초간 강조한다. 이동 경로는 표시하지 않으며 실행 중에는 위치 찾기를 잠근다. 목록 위에는 담은 재료 개수를 표시한다.
- 목록에 있는 물건은 어느 순서로 담아도 된다. 각각 +50점이며 만점은 초1–3 150점, 초4–6 250점이다. 양말·축구공·로봇처럼 목록에 없는 물건이나 중복으로 담은 물건은 −20점이다.
- 엉뚱한 물건은 양말·축구공·로봇·마이크·왕관·로켓·마술봉·북·자석·오리인형 10종이다. 집으면 물건별 이야기·소품·효과음이 있는 실패 연출이 발동한다. −20점을 반영하고 남은 블록을 중단한다. 종료하기를 연결한 정식 실행에서는 이름을 입력해 도전 기록을 명예의 전당에 남길 수 있다.
- 바닥 함정은 물웅덩이·미끄러운 바닥·얼음판·바나나껍질·진흙·거미줄·꿀웅덩이·장난감블록 8종에서 무작위로 배치한다. 밟으면 미끄러지거나 잠깐 달라붙는 연출과 함께 −10점이다. 같은 함정은 한 실행에서 한 번만 감점하며, 모든 지도에 함정을 피해서 목록 전체를 담을 수 있는 길이 있다.
- 필요한 재료를 모두 담고 끝냈다면 함정 감점이 있어도 **심부름 완료!**와 성공 효과음을 표시한다. 함정 감점과 최종 점수는 그대로 반영한다.
- 두 난이도 모두 통로 사이에 연결 길을 둔다. 같은 칸을 되짚지 않고 함정을 피해 모든 물건을 담는 경로가 있으며, 초1–3은 12칸, 초4–6은 24칸 이내다. 물건 간 간격과 갈림길은 유지한다.
- 같은 난이도의 풀이 부담이 비슷하도록 새 지도의 최단 안전 이동과 최소 동작 풀이를 검사한다. 입구에서 동쪽을 보고 출발해 재료를 모두 담는 기준 풀이는 초1–3 이동 9–10회·회전 3–4회, 초4–6 이동 20–22회·회전 6–7회 범위다. 집기와 종료까지 포함한 최소 동작은 각각 16–18회와 32–34회다. 같은 최소 동작의 경로가 여럿이면 회전이 적은 경로를 비교한다. 실제 풀이 시간은 사용자의 계획과 블록 사용 방법에 따라 달라진다.
- **시작하기**에 연결된 블록만 실행한다. 시작하기와 **종료하기**는 각각 하나만 놓을 수 있으며, 분리된 블록은 실행과 결과 블록 수에 포함하지 않는다. 종료하기를 만나면 점수를 계산한다. 중첩 반복은 600회 실행 한도를 넘기면 중단한다.
- 종료하기를 연결하지 않은 코드는 미리보기로 실행한다. 끝나면 삐삣 소리와 함께 캐릭터·수집·함정 상태가 처음으로 돌아오며 지도·코드·풀이 시간은 유지한다. 결과와 이름 입력창은 열지 않는다. 종료하기가 연결되어 있어도 실제로 실행하지 못하고 코드가 끝나면 같은 방식으로 돌아온다.
- 실행 버튼은 연결된 종료하기가 없으면 **미리보기**, 있으면 **결과까지 실행**으로 표시한다. 처음 화면의 난이도 카드에는 학년과 함께 재료 개수·지도 크기를 표시한다.
- **새 맵**은 새 랜덤 지도로 바꾸고 작성한 블록은 유지한다. 실행·미리보기·다시 도전은 지도와 코드를 유지한다. 홈으로 나간 뒤 새 게임을 시작하면 시작 블록으로 초기화한다.
- 게임 안의 **홈으로** 버튼으로 실행 중에도 처음 화면에 돌아갈 수 있다.

## 풀이 시간과 명예의 전당

- 처음 시작할 때는 안내를 확인한 시각부터 상단 타이머와 서버의 풀이 시간을 측정한다. 안내를 읽는 시간은 순위 기록에서도 제외하고, 확인 요청을 다시 보내도 최초 시작 시각을 유지한다. 종료하기나 정식 실패 엔딩으로 실행이 끝나면 이름 입력 모달이 먼저 열린다. 이름 입력과 결과 화면을 보는 시간은 풀이 시간에서 제외하며, 미리보기 시간은 풀이 시간에 포함한다.
- 같은 맵에서 다시 도전하면 지도와 코드를 유지하고 이전 풀이 시간을 누적한다. 새 맵에서는 새 타이머를 시작한다.
- 기록은 같은 난이도·지도·장보기 목록 안에서 점수 내림차순, 풀이 시간 오름차순으로 정렬한다. 완전히 같은 기록은 먼저 등록한 순서로 표시한다. 전당에 현재 도전과 정렬 기준을 항상 표시한다.
- 서버를 재시작해도 이미 시작한 도전과 재도전의 지도는 유지된다. 기존 명예의 전당 기록도 삭제하지 않고 원래 지도에 연결한다.
- 점수와 풀이 시간은 서버에서 확정한다. 서버는 시작할 때 지도를 저장하고 제출된 블록 프로그램을 같은 엔진으로 다시 실행한다.
- 종료하기 또는 이스터에그 엔딩으로 끝난 정식 실행만 등록할 수 있다. 종료하기를 연결하지 않은 미리보기는 이스터에그가 발생해도 기록을 제출하지 않는다.
- SQLite 데이터는 기본적으로 저장소 바깥 `../work/asv-leaderboard.sqlite`에 저장한다. `--db /절대/경로/leaderboard.sqlite`로 변경할 수 있으며 웹 정적 파일 경로 바깥에 둔다. 서버를 재시작해도 기록은 유지된다.
- 결과의 지도에는 실제로 지나간 칸, 수집한 물건, 멈춘 위치를 표시한다.

## 테스트

```bash
node test/engine.test.js
node test/blocks.test.js
node --test test/server.test.cjs
node --test test/pwa.test.cjs
```

엔진 규칙과 함정 감점을 검증하고, 각 난이도 160개 시드에서 모든 물건의 도달 가능성, 함정 없는 짧은 수집 경로, 이동·회전·최소 동작의 난이도 범위, 연결 통로와 지도의 다양성을 확인한다. `NauEngine.generateLevel(idOrLevel, random?)`에 난수 함수를 전달하면 같은 시드로 지도를 재현할 수 있다.

이전 케이크 데모의 기획 기록은 [docs/spec.md](docs/spec.md)에 남아 있다.
